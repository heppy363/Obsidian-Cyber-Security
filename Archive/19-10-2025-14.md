## Nozioni
Alcune immagini si possono eseguire e fermare al isnatne ma non rimangon oattivi i contener da esse genrati per che non hanno dei servizzi che restanno attivi e come dire che eseguiamo un programma ma senza direttive.
DI base i container sono isoalti dal sistema pricnipale quindi tutti gli input e gli aotput non si possono scambiare tra le due macchine ammeno che non si usi un certo flag 
```
docker run -it ubuntu bash
```
Cosi facendo la schel che andiamo ad eseguire la vediamo in attivta direttametne sul nostro terminale: CTRL + D -> uccide il container CONTROL + P, CONTROL + Q in questo caso il container non muore e ancora in esecuzione e ci possiamo lavorare normalmente.

con il comando `docker run <container>` lui esegue una nuova istanza a partire da una immagine sempre con un ID diverso casuale 
quando un container muore o vine fermato non muore semplicemente non e piu in esecuzione ma funzioan perfettamente e posso farlo ripartire senza probblemi 
```
docker start <nome_container>
```

Quindi per elimanre un container e i relativvi dati non basta fermarlo ma asi deve procedere con questo comando 
```
docker rm <id_container> <nome_container>
```

Nel caso in cui si volesse usare dei container one-time si puo fare con la seguente strigna 
```
docker run --rm -it --name prova-ubunto ubunto bash

```
Cosi facendo ho creto un container chiamato prova-ubunto, che usa lóutput del mio terminale e che a sua votla si auto distrugge alla chiusura del container stesso 

Per vedere tutti i container attivi si usa 
```
docker ps 
```
e con il flag `-a` posso vedere tutti i container che o avviato ma che non sono piu in esecuzione e quindi sono al cimitero

Per fermare un container 
```
docker stop <id_container> <nome>
```

Dato che spesso i container possono tenre la schll impegnata con lésecuzione dei loro processi si devono lanciare i container in modalita d tached distaccata con:
```
docker run -d <resto del comando>
```
cosi facendo il processo non ci occupa la nostra shell 

Cosi posso lanciare 10 container tutti a indieme 
```
for i in {1..10}
> do
> docker run -d ubuntu sleep 600
> done
```

Si possono lanciare piu comandi contemporaneamente su uno steso container:
```
docker run --rm -it unbunto bash -c "tutti i comandi separati da &"
```
DI fatto ogni comando e una istanza di shell dentro il container stesso.

Si posono vedere i log del container con 
```
docker logs <nome> <id>
```

Per fermare i container si possono usare due comandi 
```
doker stop <nome container>
```
Se il container e capriccioso o ci sono errori si fa 
```
docker kill <nome, id>
```
Uccide il containe e librera le risorse 

Posso limitare le risorse asegnate al mio container con il segnrte flag `--cpus` e specificare quante risorse puo usare. Principio equivalente per la memoria con `--memory`
