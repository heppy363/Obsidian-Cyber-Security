## Nozioni
- Imparare ad usare la versione da riga di comando a prescidnere da tutto 
- quanto segue e stato eseguito sempre come amministratore abbiamo usato _sudo_

con questo script posso instllare docker ovunque su linux dato che capisce in che distro in cui mi trovo usa il packet manage giusto e fa tutto in automatico 


``` 
 curl -fsSL https://get.docker.com -o get-docker.sh
 sudo sh ./get-docker.sh --dry-run
```

- Da notare come e presente il _flag_ --dry-run questo simula una installazione e non la conclude quindi nel caso si voglia fare per davvero lo si deve _eliminare_
- Se tuutto e adnato bene al termine della installazione fa un recap con tutte le info di instlalazione

```

```

- Per testare il funzionamento di docker effettivo usare il comando 
```
sudo docker run hello-world
```

Questo scarichera una piccola immagine di prova e la fara partire in un container 


## Usare docker senza sudo no root
non si usa con sudo dato che per la sicurezza non e il massimo per ragioni di sicurezza si usa docker senza usare sudo per farlo si usa questo scrip che ci da docker stesso 
```
dockerd-rootless-setuptool.sh install
```

per confermare che tutto sia andato a bun fine usare il comando 
```
systemctl status docker --user

```
