## Nozioni

- Per trovare delle imagini gia pronte al uso si puo usare il comando 
```
docker search ubuntu
```
Con questo comando certo tutte le immagini che fanno riferimento ad ubuntu , l'idea  e quella di scaricare un sistema operativo che poi a sua volta contiene un servizzio che noi vogliamo usare. 

- Per scaricare un immagine usare il seguente comando 
```
docker pull <nome immagine>:<versione> 
```
Cosi facendo scarichiamo la immagine che ci interessa, il _tag_ versione posso decidere quale versione installare e per trovare quella che a me interessa uso Dockerhab e cerco il pacchetto che mi interessa li dentro con tutte le sue versioni e descrizioni 


- Per visualizzare tutte le immagini e tutte le info di una immagine stessa usare il comando
```
docker image ls
```


 - Per rimuovere una immagine usare il comando 
```
docker rmi <nome immagine>:<versione>
```

- Per vedere come ogni singolo layer e stato creato e cosa fa nello specifico usare il comando 
```
docker history <nome immagine>
```

- Per eliminare le immgini che non sono utlizzate da alcune contanier usare 
```
docker image prune
```
