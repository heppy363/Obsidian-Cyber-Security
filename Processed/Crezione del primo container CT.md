# 📝 Lezione: Crezione del primo container CT
**Corso:** [[Dashboard H-NET]]

---
## Contenuto
Prima di creare un container CT si deve scaricare un immagine e successivamente, procedere con l'apposito pulsante **importante** nella configurazione si deve impostare una password di minimo 5 caratteri non e segnalato ma senza di essa non sara possibile procedere ulteriormente.

#### Risoluzione errori di rete 
Nel caso in cui il container non sia collegato alla rete verificare sempre i DNS basta constatare se il il comando di update del container funziona in maniera corretta oppure eseguire un ping al DNS di google _8.8.8.8_ in caso di errore andare nella gestione del DNS stesso del container e inserire quello di google potrebbe non averlo preso dalla macchina host
