# 📝 Lezione: Specifiche HW server di calcolo 1
**Corso:** [[Dashboard H-NET]]

---
## Contenuto
Questa macchina ha lo scopo di fungere da server per tre persone unicamente come centro di compilazione codice e gestione servizi considerando uno scenario di carico massimo di 12 macchine virtuali sempre in funzione.

#### Componenti HW 
- **Scheda Madre:** Supermicro X9SRE/X9SRi (Socket LGA 2011).
- **Processore:** Intel Xeon E5-2690 V2 (10 Core / 20 Thread).
- **Memoria RAM:** 128 GB DDR3 RDIMM ECC Registered (8 moduli da 16GB).
- **Dissipatore:** EKL AG Core i7 (Socket 2011).
- **Alimentatore:** DeepCool PK650D (650W).
- **Scheda Video:** NVIDIA GTX 1050 (per test output video).
