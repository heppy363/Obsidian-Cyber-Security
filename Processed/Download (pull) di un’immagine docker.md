## Nozioni
Una volta individuata l’immagine desiderata, la si può scaricare nel sistema locale con:
```
docker pull <nome_immagine>:<versione>
```
Esempio:
```
docker pull ubuntu:22.04
```
Il **tag** (qui `22.04`) indica la versione specifica dell’immagine.  
Se non viene specificato, Docker scarica automaticamente il tag `latest`, cioè la versione più recente.
> 🔍 Le versioni e i dettagli di ogni immagine sono consultabili sul sito [qui](hub.docker.com)
