# 📝 Lezione: la gerarchia dei linguaggi di programmazione
**Corso:** [[Programmazione]]

---
## Contenuto
Il software si è evoluto per allontanarsi dalla rigidità dell'hardware e avvicinarsi alla logica umana.
### 3.1 Linguaggio Macchina (Low Level)
- **Forma:** Sequenze pure di 0 e 1.
- **Pro:** Esecuzione immediata.
- **Contro:** Impossibile da scrivere o correggere per un essere umano.
### 3.2 Linguaggio Assembly (Mnemonico)
L'Assembly è una trasposizione testuale del linguaggio macchina.
- **Esempio:** Invece di `10110000 01100001`, scrivi `MOV AL, 61h`.
- **Assembler:** Il software che traduce 1:1 queste etichette in binario. È ancora **dipendente dall'hardware**: se cambi CPU, devi riscrivere l'Assembly.
### 3.3 Linguaggi ad Alto Livello (High Level)
Linguaggi come C, Java, Python o C++.
- **Caratteristiche:** Usano una **sintassi** simile all'inglese e strutture logiche complesse. Sono **indipendenti dall'hardware**: scrivi il codice una volta e il traduttore lo adatterà alla CPU specifica.
