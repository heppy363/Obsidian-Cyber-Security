## Nozioni
Per elencare tutte le immagini scaricate localmente:
```
docker image ls
```
Alias abbreviato:
```
docker images
```
Questo comando mostra:
- il **REPOSITORY** (nome dell’immagine),
- il **TAG** (versione),
- l’**IMAGE ID** (identificativo univoco),
- la **SIZE** (dimensione in disco),
- e la **CREATED** (data di creazione).
> 💡 Le immagini sono salvate nel file system locale, di solito in `/var/lib/docker`, e possono essere riutilizzate più volte per creare container.
