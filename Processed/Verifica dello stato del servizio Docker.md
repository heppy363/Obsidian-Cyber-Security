## Nozioni
Una volta completata l’installazione, è buona pratica verificare che il servizio **Docker Daemon** sia effettivamente attivo e in esecuzione.  
Questo si può fare con il comando:
```
systemctl status docker
```

Questo comando interroga il gestore dei servizi di sistema (systemd) e mostra lo stato del servizio Docker, indicando se è **attivo (running)**, **abilitato all’avvio**, o se sono presenti errori nel caricamento. Nel caso in cui non ci fossero errori nella installazione allora si puo procedere con il test Hello-World
