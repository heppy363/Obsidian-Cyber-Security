## Nozioni
Per verificare il corretto funzionamento del sistema Docker, si può eseguire un container di test:
```
sudo docker run hello-world
```
Questo comando:
1. Scarica una **piccola immagine di test** (`hello-world`) dal registro ufficiale Docker Hub.
2. Crea un container basato su quella immagine.
3. Esegue al suo interno un semplice script che stampa un messaggio di conferma.
Se il messaggio viene visualizzato correttamente, significa che Docker è stato installato e configurato con successo e che il demone è in grado di scaricare immagini ed eseguire container.
