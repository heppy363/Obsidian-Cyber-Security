## Nozioni
> E consigliato un PC con queste specifiche 4 GB+ di RAM, Connessione Internet richiesta, macOS 13.0+, Ubuntu 20.04+/Debian 10+, o Windows 10+ (con WSL 1, WSL 2, o Git per Windows) La WSL non essensiale ma molto comoda 


A seconda del sistema incollare nel terminale questo comando 
- whindow
```
irm https://claude.ai/install.ps1 | iex
```
- Linux 
```
curl -fsSL https://claude.ai/install.sh | bash
```
Non fara altro che scaricare l'ultima versione dello strumento Cloud da CLI, l'installazione ci mettera un po dato che deve anche buildarlo. 
Verificare l'installazione con il comando `claude --help` 
Lanciare il comando `claude` da qui si dovra configurare come meglio credi con la configurazione del account avviene tutto da browser. 
Una volta configurato basta accedere alla cartella di lavoro e lanciare il comando `cloude` cosi da aprire tutto la CLI con claud effettivo.
