## 📝 Note di studio

### Video lezione 3
Si tratta del cervello del nostro CP
- Legge dati dalla RAM 
- Operazioni aritemetiche 
- Spsotamento di dati da un punto della memoria ad un altro 
queste istruzini sono codificati attraverso le istruzioni di un programma si tratta di un programma che si impartisce alla CPU per eseguire un solo comando alla volta, queste istruzioni sono codificate come 0 e 1 questa tipo di codifica si defisnice _linugaggio macchina_ quindi sono in striuttura bianria e codifica ad una istruzione la CPU puo fare questo set di istruzioni si chiama istruction set ed e unico per ogni tipo di processori quindi i tratta del insime delle cose che puo fare e in particolare queste rappresetnao l'interfaccia tra quello che e il nostro programma e il nostro SW.
- Ogni istruzione e stremamente semplice ma per ottere risultati significati si devono contanera le istruzioni 
- La CPU esegue in maniera rapida e precisa il loro istruction set 
- Se vie e una errore logico la CPU non lo riconosce esegue solo le istruzioni 

**Ciclo di esecuzione di un programma**
1) Dal disco rigido i programmi vengono caricati in RAM 
2) Dalla ram la CPU usegue le singole istruzioni del programma 

Il ciclo fetch decode execute -> si ripete per ogni istruzione del programma 
1) Fetch la PCU preleva lestruzioni in lunguagigo macchina 
2) Decode la CPU interpreta quelle istruzionie inbianrio per capire quale istruzione deve eseguiure 
3) Execute LA cup esegue l'operaizone 
questo ciclo si ripete fino alla fine del programma 


il linguaggio macchina e comprensibile alla macchina ma non dal essere umano 
1) si introduce il linguaggio assembly semplifica il lavoro 
	1) codici mnemoici Add Muv Mul 
	2) rende piu comprensibile il programma per i programamtori 
con questo linguaggio server un assembler che converte le nostre istruzioni in linguagigo macchina 
2) dato che ogni CPU ha il suo set di istruzioni allora per ogni CPU serve il suo assembler quindi si dice che questo linguaggio e basato sul HW 
Negli anni 50 si arriva ai linguaggi ad alto livello qui ci si concentra sulla strutura del programma e non sul istruction set, quindi nei linguaggi ad altri livello consentono di scrivre codice in mniera comatatta e coincisa questi lingauggi utilizznao le cosi dette keyword quindi parole riservate che hanno un motivo specifico di esistere dentro il programma abbiaomo gli oeratori, aritmetici, la sintassi rappresenta l'insime di regole con il quale si scrive in quel linguaggio 
3) le istruzioni sono le unita fondamenti del programma e corrissponde ad un set di operazioni elementari che compie la CPU 
per fare si che il nostro codice possa essere eseguito dalla nostra CPU abbiamo bisogno di un compilatore o di un interprete che dal nostro linguaggio di partenze arriva al linguaggio macchina 
4) compilatori -> il processo di compilazione e differente dal processo di esecuzione una volta copilato lo si puo eseguire quante volte si vuole 
5) Interprete -> istruzioni pe istruzione viene tradotto al livello linguaggio macchina si traduce e si esege questo ciclo lo si esegue fino al termie del programma questo e molto utile per capire se il nostro progamma fa quello che vogliamo 
il programam che scriviamo si chiama sorgente
